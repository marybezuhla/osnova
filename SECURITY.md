# Безпека · Security

## Як повідомити про вразливість · Reporting a vulnerability

Будь ласка, не пишіть про вразливість у відкритих issues. Скористайтеся приватним повідомленням: вкладка **Security → Report a vulnerability** у цьому репозиторії.

Please do not report a vulnerability in public issues. Use a private report: **Security → Report a vulnerability** in this repository.

- Відповідь — протягом **3 днів**. · A reply within **3 days**.
- Виправлення серйозної вразливості — протягом **7 днів**, з новим випуском і поясненням у його описі. Решта — у найближчому випуску. · A fix for a serious vulnerability within **7 days**, in a new release with an explanation in its notes. Anything else in the next release.

Помилку в тексті Конституції теж можна повідомити так: текст має бути слово в слово з офіційним. · A mistake in the Constitution's text can be reported the same way: the text must match the official one word for word.

## Підтримувані версії · Supported versions

Лише остання версія. · Only the latest version.

Потрібен **Android 8** або новіший, щоб Основу можна було встановити й на старі шкільні планшети та телефони. Версії, старші за Android 12, уже не отримують оновлень безпеки, тож на них слабший захист самого телефона; Основа ж не має доступу до інтернету й не приймає нічого від інших застосунків. · Requires **Android 8** or newer, so that Osnova also installs on old school tablets and phones. Versions older than Android 12 no longer get security updates, so the phone itself is less protected; Osnova has no internet access and takes nothing in from other apps.
